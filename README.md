# 📚 Library Management System

A console-based Library Management System developed in Java to manage book inventory, issue-return workflows, and transaction records in a structured and maintainable way.

This project demonstrates the implementation of modular class design and object-oriented programming principles to simulate real-world resource management systems.

---

## ✨ Key Functionalities

- Book Inventory Management  
- Book Issue & Return Tracking  
- Record Search using Unique Identifiers  
- Transaction Monitoring  
- Structured Console-Based Interface  

---

## 🛠 Technology Stack

- Java  
- Object-Oriented Programming (OOP)  
- Java Collections Framework  
- IntelliJ IDEA
